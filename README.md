# Build-A-LLM-From-Scratch
This repository is intended in keeping track in what i've learned in Sebastian Raschka's book "Build a large language model" 
If you want a sequential way of looking through this project follow the sequence of table of contents below..

# Table of Contents

## 1. Tokenization Basics
**Description:**  
Text preprocessing, vocabulary construction, subword tokenization (BPE), token IDs and attention masks.

**Notebook:**  
- `tokenization_basics.ipynb`

---

## 2. Attention Mechanisms
**Description:**  
Scaled dot-product attention, self-attention, and multi-head attention with mathematical intuition and examples.

**Notebook:**  
- `attention_mechanisms.ipynb`

---

## 3. Architecture
**Description:**  
Transformer architecture, embeddings, positional encoding, encoder–decoder vs decoder-only models, and block structure.

**Notebook:**  
- `architecture.ipynb`

---

## 4. Pretraining
**Description:**  
Language modeling objectives, causal vs masked language modeling, training loops, and loss functions.

**Notebook:**  
- `pretraining.ipynb`

---

## 5. Classification
**Description:**  
Applying pretrained models to text classification, adding classification heads, evaluation metrics, and inference.

**Notebook:**  
- `classificationLLM.ipynb`

---

## 6. Fine-Tuning
**Description:**  
Full fine-tuning, layer freezing, parameter-efficient fine-tuning

**Notebook:**  
- fine_tuning.ipynb`
